# Harinfood Bel HP

Aplikasi Android yang mengubah perangkat iTag (tracker Bluetooth) menjadi bel pintu:

- Saat tombol di iTag ditekan, aplikasi memutar mp3 pilihan (atau nada bel bawaan).
- Tombol **Bunyikan** di aplikasi membuat iTag berbunyi.
- Berjalan sebagai layanan latar depan agar koneksi tetap hidup.

## Cara memakai
1. Nyalakan Bluetooth dan izinkan akses Bluetooth/lokasi.
2. Tekan **Pilih iTag**, lalu ketuk iTag dari daftar.
3. (Opsional) tekan **Pilih MP3** untuk memilih bel sendiri.
4. Tekan tombol iTag untuk menguji bel. Tekan area bel di layar untuk membunyikan iTag.

## Catatan
- Matikan aplikasi iTag resmi, karena iTag biasanya hanya bisa terhubung ke satu HP dalam satu waktu.
- Jangan pasangkan iTag lewat menu Bluetooth bawaan HP. Cukup pilih lewat aplikasi ini.
- Matikan optimasi baterai untuk aplikasi ini agar layanan tidak berhenti di latar belakang.
- Jika tombol iTag tidak merespons, tahan kartu status untuk melihat info GATT, lalu kirim isinya untuk penyesuaian.
